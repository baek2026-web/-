## 📊 구글 스프레드시트 연동 상태

  `https://docs.google.com/spreadsheets/d/1kXDBc91-7SyQhcbC_dZLszNJcF3oKDbfs5kItjEn344/edit?gid=0#gid=0`

- **현재 스프레드시트에서 동기화된 수업**:
  1. **원소 탐구실**: `https://imuzikr.github.io/test01/`
  2. **산-염기 중화반응**: `https://imuzikr.github.io/test02/`

스프레드시트에 새로운 행(제목, url)을 추가하시면 포털 로비에 새로운 수업 카드가 실시간으로 자동 추가됩니다!

1. **스프레드시트 열 이름 규칙**:
   - 구글 스프레드시트의 첫 번째 행(1행)에 **`제목`**과 **`url`**이 입력되어 있어야 합니다.

2. **구글 시트 공유 권한**:
   - 스프레드시트 우측 상단 **[공유]**에서 **'링크가 있는 모든 사용자 - 뷰어'**로 설정되어 있어 안전하고 편리하게 로딩됩니다.

3. **연동 주소 변경 방법**:
   - `index.html` 우측 상단의 **[스프레드시트 연동 설정]** 버튼을 클릭하여 언제든 새로운 구글 시트 주소로 교체할 수 있습니다.

## 💻 실행 방법
1. 바탕화면의 `테스트` 폴더에서 **`index.html`** 파일을 더블 클릭하시면 크롬, 엣지, 웨일 등 웹 브라우저에서 즉시 열립니다.
